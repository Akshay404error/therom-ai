# Technical Stack

## Core Technologies

### Frontend
- **HTML5** - For structuring the web interface
- **CSS3** - For styling the user interface
- **JavaScript** - For client-side interactivity
- **WebAssembly** - For running the theorem prover efficiently in the browser

### Backend (Server-side Components)
- **Python 3.8+** - Primary language for the theorem prover and demo scripts
- **Flask/Django** (Inferred from web interface) - For web server implementation

### Build & Package Management
- **Lake** - Build system and package manager (evident from lakefile.toml files)
- **TOML** - Configuration file format for build settings

## Development Tools
- **Git** - Version control
- **Markdown** - Documentation
- **Web Browsers** (Chrome, Firefox, Edge) - For testing the web interface

## Architecture
- **Client-Server Architecture** - Web-based frontend with backend processing
- **Interactive Theorem Proving** - Core functionality for mathematical reasoning
- **Functional Programming** - Core language paradigm

- **Cross-platform** - Works on Windows, macOS, and Linux
